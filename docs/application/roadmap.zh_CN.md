## 下一批小任务，按顺序执行

1. **A1：恢复可复现的模拟器互动。** 用未修改的归档镜像及匹配 ELF 复现短按与明确按住／松开的长按，区分模拟器输入／运行时问题和应用问题。仅用于模拟器的诊断不进入正式固件。验收：同一确切镜像展示欢迎弹窗开关、两个焦点、门口中间帧、往返终点、唤醒按键消耗。若受阻，保留 PARTIAL，主机渲染只作为补充。
2. **A2：收口真机 Milestone A。** 确切设备／镜像获得明确烧录授权后，验证冷启动、角色／弹窗可读性、三键映射、往返转场、闲置背光和首次唤醒。限时检查启动看门狗，启动通过不代替 UI 验收。在现有验证记录登记镜像身份与观察结果。
3. **A3：保护已完成成果。** 验证真实 Wi-Fi 配网／重连、离线冷启动、运行周期刷新、保守校时衔接、第五杯不推进成长、阶段边界、开花后记杯和重启保留。发现失败先做针对性修复。这是验收现有功能，不是扩展 Milestone A。

2026-10-08 后续迭代修复转场期间稳定松开后残留的输入保护，并增加原始按键流程回归。模拟器互动仍为 PARTIAL，真机验收仍待完成。每批只处理一个可复现问题、必要的小修复、相关回归检查及验收记录。
